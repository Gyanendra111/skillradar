Personal roadmap

Learn enough to start applying, then improve with evidence.

A roadmap is not a promise of employment. It is a working plan that connects a target role to demonstrable skills and real application practice.

Target role

Entry-level Data Analyst · India · 0 to 2 years

Learn first

SQL querying, spreadsheet cleaning, and one visualisation workflow.

Practise and demonstrate

Build a small project that answers a defined business question and document your decisions.

Start applying

Apply when you can complete the core tasks and explain your work clearly. Do not wait for every advanced topic.

Continue alongside applications

Add Python automation, statistics, and domain knowledge as the market evidence and your target roles require.

Personalisation comes next.
Choose the topics you already know, add a target company, and the future Python service can produce a saved roadmap without requiring an account.

What a useful roadmap contains

  • Skill and topic prerequisites
  • A concrete proof-of-work task
  • A clear application threshold
  • Optional topics separated from essentials
